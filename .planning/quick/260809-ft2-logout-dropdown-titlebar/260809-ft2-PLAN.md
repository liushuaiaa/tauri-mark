# Quick Task 260809-ft2: 退出入口移到顶部下拉

## 背景

侧边栏收起时，退出按钮展示在图标按钮上方很丑。用户希望调整位置：移到顶部天气左侧的「记事本」标题上，hover 时展示下拉菜单，下拉第一行显示当前用户信息，第二行显示退出。

## 变更

### 1. `src/components/TitleBar.vue`
- 「记事本」标题（登录态）包一层 `el-dropdown`（`trigger="hover"`）
- 下拉内容：第一行当前用户信息（`currentUsername`），第二行「退出登录」（`divided` 分隔）
- `@command="handleUserCommand"`：`logout` 命令 → 调用 store `logout()` → `ElMessage` 提示 → `router.push('/login')`
- 未登录（含登录页）时保持纯标题，不显示下拉
- 新增 imports：`useRouter`、`isLoggedIn/currentUsername/logout`、`User`/`SwitchButton` 图标、`ElMessage`

### 2. `src/components/AppSidebar.vue`
- 移除展开态 header 的退出按钮
- 移除折叠态 footer 的退出按钮
- 移除 `handleLogout` 及不再使用的 imports（`SwitchButton`、`logout`、`ElMessage`、`ElMessageBox`）
- 清理对应样式（`.logout-btn`、`.footer-logout-btn`、`.sidebar.collapsed .sidebar-footer` 列布局）

## 验收

- [ ] 侧边栏（展开/收起）均无退出按钮
- [ ] 顶部「记事本」hover 弹出下拉：第一行用户名，第二行退出
- [ ] 点退出 → 确认/直接退出 → 回登录页，本地凭据清除
- [ ] 登录页不显示下拉
- [ ] `npx vue-tsc --noEmit` 通过
