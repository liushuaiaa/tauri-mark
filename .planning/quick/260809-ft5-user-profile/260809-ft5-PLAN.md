# Quick Task 260809-ft5: 个人信息页（基本信息 + 修改密码）

## 背景

上一版修改密码页复用了登录页的「居中卡片 + 灰渐变」样式，用户误以为进入了登录/注册页。需改为真正的应用内页面：展示用户基本信息（用户名、用户ID），并可修改密码。继续不显示左侧边栏（页面不加入侧边栏导航），增加返回入口。

## 变更

### `src/stores/auth.ts`
- 新增 `currentUserId` ref（从 localStorage `auth_userid` 初始化）
- 修正 userId 读取：后端 Jackson SNAKE_CASE 返回 `user_id`，原代码读 `response.data.userId` 为 undefined；新增兼容读取 `readUserId(data)`（`user_id ?? userId`）
- register / login / validateToken 更新 `currentUserId`，logout 置 null

### `src/views/user/index.vue`（替换 change-password.vue）
- 页面标题「个人信息」
- 「基本信息」卡片：用户名、用户ID
- 「修改密码」卡片：原密码/新密码/确认新密码，SHA-256 哈希提交
- 顶部「返回」按钮 → `router.push('/')`
- 样式与设置页一致（`--color-bg-page` #FAFAFA 底 + 白色卡片），不复用登录页样式

### `src/router/index.ts`
- 路由改为 `/user`，name `profile`，组件 `views/user/index.vue`

### `src/App.vue`
- `showSidebar` 排除 `profile`（原 `change-password`）

### `src/components/TitleBar.vue`
- `profile` 命令跳转 `/user`（原 `/user/password`）

## 验收

- [ ] 点击顶部下拉用户信息进入「个人信息」页（非登录/注册页样式）
- [ ] 展示用户名、用户ID
- [ ] 可修改密码，成功后提示
- [ ] 页面不出现在左侧边栏导航，无侧边栏，有返回按钮
- [ ] `npx vue-tsc --noEmit` 通过
