# Quick Task 260809-ft4: 修改密码页 + 用户信息可点击 + 移除设置页退出

## 背景

1. 删除设置页「账号」下的退出登录按钮（退出已迁移到顶部下拉）
2. 左上角 hover 下拉的第一行用户信息改为可点击
3. 点击后进入新的「修改密码」页面
4. 新页面不出现在左侧边栏（整页无侧边栏，同 editor/day 模式）

## 后端（修改密码接口）

### `dto/ChangePasswordRequest.java`（新建）
- 字段 `oldPassword` / `newPassword`（Jackson 全局 SNAKE_CASE → 请求体 `old_password` / `new_password`）

### `mapper/UserMapper.java`
- 新增 `updatePassword(id, password)`：`UPDATE sys_user SET password=#{password}, updated_at=NOW() WHERE id=#{id}`

### `service/AuthService.java`
- 新增 `changePassword(userId, oldPassword, newPassword)`：查用户 → 校验原密码 → 更新

### `controller/AuthController.java`
- 新增 `POST /change-password`：从 SecurityContext 取 userId（带 token 时 JWT 过滤器已填充），调用 service，成功返回 `ApiResponse.success()`；异常 400

## 前端

### `src/api/type/auth.ts`
- 新增 `ChangePasswordRequest { old_password, new_password }`（snake_case 对齐后端）

### `src/api/auth.ts`
- `AuthApi` 新增 `changePassword`

### `src/views/user/change-password.vue`（新建页面）
- 表单：原密码 / 新密码 / 确认新密码，CryptoJS SHA-256 哈希后提交
- 成功提示并跳回上一页/首页

### `src/router/index.ts`
- 新增路由 `/user/password`，name `change-password`

### `src/App.vue`
- `showSidebar` 排除 `change-password`（不显示左侧边栏）

### `src/components/TitleBar.vue`
- 下拉第一行用户信息改为 `el-dropdown-item command="profile"`，点击 `router.push('/user/password')`

### `src/views/settings/index.vue`
- 删除「账号」退出登录 section，移除未用的 `logout`/`ElMessageBox` import
